
# OBSIDIAN COMPANION RULES

Use ~/.obsidian-companion/IDENTITY.md for identity and personality.
Use ~/.obsidian-companion/MEMORY.md for shared developer context.
Read the matching project memory in ~/.obsidian-companion/projects/.

Before significant work:
1. Inspect the relevant architecture.
2. Check previous decisions and known issues.
3. Explain risks before destructive changes.
4. Preserve unrelated functionality.
5. Run appropriate tests.
6. Report exact files changed and actual test results.

Never expose secrets or credentials.
Never publish an OTA update or release without explicit approval.
Never modify the separate legacy OS project.
